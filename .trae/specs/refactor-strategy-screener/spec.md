# 策略选股页重构 Spec

## Why
当前「智能选股页」包含公式编辑、选股配置、回测三个 Tab，回测功能与选股耦合在同一页面，职责不清晰。需将回测功能完全剥离为独立页面，本页仅保留选股相关功能，并重命名为「策略选股」。选股结果表格新增「回测」操作列，建立与回测中心的跳转关联。

## What Changes
- **BREAKING**：「智能选股」页面重命名为「策略选股」，顶部 Tab 文字改为「策略选股」
- **BREAKING**：移除主区域「回测」Tab，主区域仅保留「公式编辑」和「选股配置」两个 Tab
- **BREAKING**：移除回测 Tab 对应的全部 HTML（回测参数、指标卡片、收益曲线、交易明细、空状态）
- 选股结果表格新增「操作」列，含「回测」文字链接按钮，点击跳转到回测中心并自动填入该股票
- 选股结果表格表头新增「行业」「信号类型」「入选时间」列的对齐与排序优化
- 涨跌幅列正数红色、负数绿色（遵循 A 股习惯）

## Impact
- Affected code: `templates/index.html`（Tab 文字改、回测 Tab HTML 删除、结果表格新增操作列）、`static/app.js`（回测相关 JS 逻辑删除、结果表格渲染新增操作列、跳转回测中心逻辑）、`static/style.css`（回测相关样式可保留供回测中心复用）

## ADDED Requirements

### Requirement: 选股结果回测跳转
选股结果表格操作列 SHALL 提供「回测」文字链接按钮，点击后跳转到回测中心页并自动将该行股票代码和名称填入回测标的输入框，新建一个回测方案。

#### Scenario: 点击回测跳转
- **WHEN** 用户在选股结果表格某行点击「回测」按钮
- **THEN** 页面切换到回测中心，自动新建回测方案，回测标的字段填入该股票代码和名称

## MODIFIED Requirements

### Requirement: 选股结果表格
原表格列为：代码、名称、现价、涨跌幅、市值(亿)、成交额(亿)、信号类型、入选时间、行业。修改为新增「操作」列（含回测按钮），列顺序调整为：代码、名称、现价、涨跌幅、市值(亿)、成交额(亿)、行业、信号类型、入选时间、操作。涨跌幅正数红色、负数绿色。

## REMOVED Requirements

### Requirement: 回测 Tab
**Reason**: 回测功能完全迁移到独立的回测中心页
**Migration**: 回测 Tab 的全部 HTML 和 JS 逻辑删除；回测能力由新增的回测中心页承载；`/api/screen/backtest` 接口保留但前端不再从选股页调用
