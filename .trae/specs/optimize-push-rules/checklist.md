# Checklist

## 组合条件规则
- [ ] 单条规则支持多个子条件（conditions 数组）
- [ ] 子条件间支持 AND（全部满足）和 OR（任一满足）逻辑
- [ ] check_rules 正确评估组合条件
- [ ] 旧单条件规则自动兼容转换为 conditions 数组

## 多渠道推送
- [ ] 支持飞书、钉钉、企业微信三种 webhook 配置
- [ ] 规则可选择推送渠道
- [ ] 触发时按 channel 字段发送到对应渠道

## 推送历史记录
- [ ] 推送历史 JSON 文件保存最近 100 条
- [ ] `/api/rules/history` 接口返回推送历史
- [ ] 推送规则页有推送历史卡片
- [ ] 历史列表含时间、规则名、指标值、渠道、结果

## 规则列表内联编辑
- [ ] 规则列表含「最后触发时间」列
- [ ] 点击规则行展开内联编辑表单
- [ ] 内联编辑可修改条件/阈值/冷却/提醒内容/渠道
- [ ] 保存后规则立即生效

## 添加规则表单
- [ ] 添加规则表单支持动态增删子条件
- [ ] 支持 and/or 逻辑选择
- [ ] 支持选择推送渠道

## 回归验证
- [ ] 后台定时规则检查正常工作
- [ ] 飞书推送功能不受影响
- [ ] 选股定时推送功能不受影响
