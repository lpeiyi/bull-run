# 回测中心独立页 Spec

## Why
当前回测功能作为智能选股页的一个 Tab 存在，使用可视化条件构建器（下拉选指标+比较符+参考值），无法满足用户自定义复杂买卖逻辑的需求。需将回测升级为独立顶级页面，采用 Python 代码编辑器模式，用户编写策略代码同时定义买入和卖出逻辑，回测引擎逐 Bar 执行模拟交易。

## What Changes
- **BREAKING**：新增独立顶级页面「回测中心」，通过顶部一级导航栏进入
- **BREAKING**：顶部导航栏从当前 5 Tab 结构改为一级导航栏，含「策略选股」和「回测中心」两个入口
- 回测中心左侧新增「我的回测方案」列表面板（搜索 + 新建 + 方案卡片）
- 回测中心主工作区上半区域为配置和代码编辑区（参数栏 + Python 代码编辑器），下半区域为回测结果区
- 参数栏含：回测标的（联想搜索）、回测区间（日期范围）、初始资金、手续费率、滑点、复权方式，支持展开/收起
- Python 代码编辑器替代原可视化条件构建器，支持行号、语法高亮、自动补全、括号匹配、缩进、语法错误提示
- 编辑器右侧可折叠「API 参考」面板，按分类列出可用 API 函数
- 代码需包含三个生命周期函数：initialize(context)、before_trading_start(context)、handle_bar(context, bar)
- 提供 API：数据获取（history_bars 等）、技术指标（MA/MACD/KDJ/RSI/BOLL/VOL）、交易下单（order/order_target 等）、账户信息（context.portfolio）
- 回测结果区：7 个核心指标卡片（累计收益率/年化/最大回撤/胜率/盈亏比/交易次数/夏普比率）
- 收益曲线图（策略 vs 基准）+ 回撤曲线图（面积图）
- 逐笔交易明细表（含买入/卖出触发原因、可展开、导出 CSV）
- 回测日志 Tab（按级别着色、级别筛选）
- 代码模板下拉（MACD/双均线/布林带/RSI/网格等策略模板）
- 回测中状态：按钮变「回测中...」+ 进度条、控件置灰、完成后自动滚动到结果区
- 参数变更后显示黄色提示条「参数已变更...」

## Impact
- Affected code:
  - `app.py`：新增回测中心相关 API（回测方案 CRUD、Python 代码回测执行、股票联想搜索）
  - `templates/index.html`：顶部导航栏改造、新增回测中心页 HTML
  - `static/app.js`：回测中心页面逻辑、代码编辑器集成、回测结果渲染
  - `static/style.css`：回测中心布局与深色主题样式
  - `core/backtest.py`：新增 Python 代码模式回测引擎（沙箱执行用户代码，逐 Bar 调用 handle_bar）
  - 新增：回测方案持久化（JSON 文件存储方案列表）
  - 前端需引入代码编辑器组件（CodeMirror 或 Monaco Editor）

## ADDED Requirements

### Requirement: 回测中心独立页面
系统 SHALL 提供独立顶级页面「回测中心」，通过顶部导航栏进入，与策略选股页完全独立，各自有左侧面板和主工作区。

#### Scenario: 进入回测中心
- **WHEN** 用户点击顶部导航「回测中心」
- **THEN** 显示回测中心页面，左侧为回测方案列表，右侧为配置区+代码编辑器+结果区

### Requirement: Python 代码编辑器
系统 SHALL 提供专业 Python 代码编辑器替代原可视化条件构建器，支持行号、语法高亮、自动补全、括号匹配、缩进、语法错误行内提示。代码必须包含 initialize(context)、handle_bar(context, bar) 两个函数，回测引擎按生命周期调用。

#### Scenario: 编写策略代码
- **WHEN** 用户在代码编辑器中编写 Python 策略代码
- **THEN** 编辑器提供语法高亮、自动补全、行号显示，语法错误行显示红色波浪线

#### Scenario: 代码有语法错误
- **WHEN** 用户代码存在语法错误
- **THEN** 「开始回测」按钮置灰，显示错误数量和第一条错误信息

### Requirement: 回测引擎执行用户代码
系统 SHALL 在沙箱环境中执行用户编写的 Python 策略代码，按 initialize → before_trading_start → handle_bar 生命周期逐 Bar 调用，模拟交易并记录净值曲线、交易明细、日志。

#### Scenario: 执行回测
- **WHEN** 用户点击「开始回测」且代码无语法错误
- **THEN** 回测引擎逐 Bar 执行 handle_bar，显示进度条，完成后展示指标卡片、收益曲线、回撤曲线、交易明细

### Requirement: 回测结果展示
系统 SHALL 在回测结果区展示 7 个核心指标卡片（累计收益率、年化收益率、最大回撤、胜率、盈亏比、交易次数、夏普比率）、收益曲线图（策略 vs 基准）、回撤曲线图（面积图）、逐笔交易明细表（可展开显示触发原因、可导出 CSV）。

#### Scenario: 回测完成
- **WHEN** 回测执行完成
- **THEN** 自动滚动到结果区顶部，展示指标卡片、图表、交易明细表

### Requirement: 回测方案管理
系统 SHALL 提供回测方案的持久化管理，左侧面板列出所有方案，支持新建、搜索、选中加载。每个方案保存配置参数、策略代码和最近回测结果。

#### Scenario: 加载已有方案
- **WHEN** 用户点击左侧方案列表中的某方案
- **THEN** 右侧加载该方案的配置参数、代码和回测结果

### Requirement: 顶部一级导航栏
系统 SHALL 在页面最顶部设置横向一级导航栏，包含「策略选股」和「回测中心」两个入口，当前页面用蓝色文字加底部下划线标识。

#### Scenario: 页面切换
- **WHEN** 用户点击导航栏中的「策略选股」或「回测中心」
- **THEN** 整个内容区域切换到对应页面，不保留另一页面的滚动位置和临时状态
