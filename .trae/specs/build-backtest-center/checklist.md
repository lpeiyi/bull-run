# Checklist

## 顶部导航栏
- [ ] 顶部一级导航栏含「策略选股」和「回测中心」两个入口
- [ ] 当前页面导航项蓝色文字 + 底部蓝色下划线，未选中为浅灰色
- [ ] 点击导航项可切换页面，内容区整体刷新

## 回测中心布局
- [ ] 左侧「我的回测方案」面板含搜索框、方案列表、新建按钮
- [ ] 方案列表项显示方案名称、标的代码名称、最后回测时间、累计收益率（正红负绿）
- [ ] 选中方案有蓝色竖边框高亮
- [ ] 主工作区顶部标题「回测中心」+ 「新建回测」+ 「保存方案」按钮
- [ ] 配置区在上（约45%高度）、结果区在下（约55%高度）

## 参数栏
- [ ] 含回测标的（联想搜索）、回测区间、初始资金、手续费率、滑点、复权方式
- [ ] 回测标的输入支持代码或名称联想，选中显示「代码 名称」格式
- [ ] 参数栏右侧有展开/收起箭头，收起时只保留标的和区间

## 代码编辑器
- [ ] 用代码编辑器完全替代原可视化条件构建器（买卖规则卡片已移除）
- [ ] 编辑器有「策略代码」和「回测日志」两个 Tab
- [ ] 代码模板下拉含 MACD/双均线/布林带/RSI/网格策略，选中填充示例代码
- [ ] 编辑器支持行号、Python 语法高亮、自动补全、括号匹配、缩进、语法错误波浪线
- [ ] 右侧可折叠「API 参考」面板，按分类列函数，点击插入代码片段
- [ ] 代码语法错误时「开始回测」按钮置灰并显示错误提示

## 回测引擎与 API
- [ ] 回测引擎正确调用 initialize/before_trading_start/handle_bar 三个生命周期函数
- [ ] 提供数据获取类 API（history_bars/get_price/attribute_history）
- [ ] 提供技术指标类 API（MA/MACD/KDJ/RSI/BOLL/VOL）
- [ ] 提供交易下单类 API（order/order_target/order_value/order_target_value/order_target_percent）
- [ ] 提供账户信息 API（context.portfolio.available_cash/total_value/positions 等）
- [ ] MACD 返回值含 diff/dea/hist 及 _prev 值

## 回测结果
- [ ] 7 个指标卡片：累计收益率/年化/最大回撤/胜率/盈亏比/交易次数/夏普比率
- [ ] 累计/年化收益率正红负绿，最大回撤显示负数且绿色
- [ ] 收益曲线图：策略蓝实线 + 基准灰虚线，含网格/图例/tooltip
- [ ] 回撤曲线图：红色半透明面积图，最低点标注数值和日期
- [ ] 交易明细表：序号/买入日期/买入价/卖出日期/卖出价/持仓天数/收益率/盈亏金额
- [ ] 交易明细行可展开显示买入/卖出触发原因
- [ ] 收益率和盈亏金额列盈利红色亏损绿色
- [ ] 交易明细表有「导出 CSV」按钮
- [ ] 表格底部有汇总行（总盈利/总亏损/净收益/平均收益率）

## 交互状态
- [ ] 点击「开始回测」后按钮变「回测中...」+ 加载动画 + 进度条
- [ ] 回测中配置区和编辑器控件置灰不可编辑
- [ ] 回测完成自动滚动到结果区顶部，按钮恢复
- [ ] 参数或代码变更后已有结果显示时出现黄色提示条 + 「重新回测」按钮
- [ ] 未回测时结果区显示空状态

## 回测日志
- [ ] 日志按时间倒序显示，含自定义日志/下单记录/系统警告错误
- [ ] 不同级别不同颜色（info 白/warn 橙/error 红）
- [ ] 有日志级别筛选下拉框和清空按钮

## 两页关联
