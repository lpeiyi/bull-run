# 牛来

专为你定制的 A股 / 基金ETF 短线盯盘工具。基于免费公开数据源，把市场概览、情绪量化、智能选股、条件推送做成了网页版，双击就能用，不需要会编程。

## 快速开始

1. 先装一次依赖（仅第一次）：
   ```
   pip install -r requirements.txt
   ```
2. 双击 `start.bat`，浏览器会自动打开 `http://127.0.0.1:8000`。
3. 用完直接关闭那个黑色窗口即可。

## 五个页面

| 页面 | 用途 |
|------|------|
| **市场概览** | 首页。多指数行情条、指数K线（含均线/成交量）、市场量能（实际/预测/分时）、情绪仪表盘、涨停梯队、炸板/跌停池、热点板块与概念 |
| **智能选股** | 用通达信公式选股。支持自定义公式编写、语法检查、全市场选股、单标的回测、定时选股推送飞书 |
| **市场情绪** | 短线情绪分（0~100）+ 历史情绪趋势曲线（可叠加指数归一化）+ 情绪冰点次日指数表现统计 |
| **推送规则** | 预设条件（如「情绪 < 30」），满足时自动推到飞书；也支持选股结果的定时推送 |
| **自选看板** | 自选标的与主要指数的实时行情 |

## 市场概览（首页）

首页聚合了盯盘所需的核心信息：

- **指数行情条**：上证、深证、创业板、科创50、上证50、中证500、沪深300、中证1000 实时行情
- **指数K线**：蜡烛图 + MA5/10/20/60/120 均线 + 成交量副图，可切换指数和周期（60/120/250日）
- **市场量能**：沪深两市实际量能、预测量能（盘中按时间比例外推）、昨日量能对比、近20日成交额走势、分时预测量能曲线
- **情绪仪表盘**：当前情绪分 + 等级 + 涨停/跌停/炸板/炸板率/晋级率/最高连板六维数据
- **涨停梯队**：按连板高度排序，含封单金额、首封时间、行业
- **炸板/跌停池**：当日炸板、跌停明细
- **热点板块**：行业涨幅榜 Top10 + 热门概念涨幅榜 Top10

## 智能选股

### 公式编辑

编写通达信公式进行选股，支持的技术指标函数：MA / EMA / SMA / REF / LLV / HHV / MAX / MIN / ABS / CROSS / RSI / MACD / KDJ / BOLL / IF / COUNT / EVERY / EXIST / BARSLAST，以及 CODELIKE / NAMELIKE / INBLOCK / CAPITAL 等股票属性函数。

支持语法：变量赋值（`:=` 中间变量 / `:` 输出变量）、逻辑运算（AND / OR / NOT）、比较运算、注释（`{ ... }`）、绘图属性自动忽略、指标属性访问（如 `KDJ.J`）。

### 选股配置

- **选股范围**：全市场 / 沪深A股 / 沪深300 / 中证500 / 自定义（沪市主板、深市主板、科创板、创业板、北交所）
- **排除条件**：ST/*ST、停牌/未交易、次新股
- **其他**：复权方式（前复权/后复权/不复权）、结果上限、排序方式
- **定时选股**：到点自动执行选股并推送飞书

### 选股回测

对单只标的用当前公式进行历史回测，显示累计收益、年化收益、最大回撤、胜率、盈亏比、交易次数，以及收益曲线和逐笔交易明细。

内置指标回测（5大经典策略）：

- **MACD 金叉死叉**：DIF 上穿 DEA 买入，下穿卖出
- **KDJ 金叉死叉**：K 上穿 D 买入，下穿卖出
- **RSI 超买超卖**：RSI 从超卖线上穿买入、超买线下穿卖出
- **布林带 均值回归**：跌破下轨买入、突破上轨卖出
- **均线 趋势跟踪**：价格上穿均线买入、下穿卖出

> 回测用前复权日K线，默认含双向万分之2.5手续费。回测结果只代表历史表现，不代表未来。

## 市场情绪

### 情绪分算法

情绪分（0~100）对齐开盘啦口径，构成如下：

- **涨停家数主导**（对数映射）：18家≈0分，150家≈90分
- **连板高度溢价**：4板+1 … 8板+5（高度是情绪的领先信号）
- **涨停晋级率修正**：昨日涨停今仍封板比例，越强=接力赚钱效应越好
- **炸板率修正**：封板率过低（炸板率 > 40%）才扣分
- **跌停惩罚**：跌停 ≤30 家视为正常，超出部分逐家递减（冰点日关键信号）

| 分数 | 状态 | 含义 |
|------|------|------|
| 0~25 | 冰点 | 涨停稀少、赚钱效应差，常是中长线分批布局区间 |
| 26~45 | 偏冷 | 适合低吸、控制仓位 |
| 46~65 | 正常 | 不温不火，按节奏操作 |
| 66~80 | 偏热 | 注意追高风险、重视止盈 |
| 81~100 | 过热 | 涨停潮常伴随分歧，短线控制仓位防回撤 |

### 历史情绪趋势

- 近15日 / 3月 / 半年 / 1年 / 全部（2020至今）可选
- 情绪分曲线 + 涨停家数柱状图 + 可叠加指数归一化曲线（上证、中证500、科创50、创业板指、沪深300）
- 历史主因子（涨停/跌停/炸板率）取自乐咕乐股，近15日叠加东财连板高度与晋级率

### 情绪冰点 · 次日指数表现

统计情绪分 ≤ 阈值（默认30，可调）的冰点日，下一交易日各指数涨跌幅，含平均涨幅、胜率统计。用于验证「冰点次日反弹」的历史规律。

## 推送规则

1. 先配置飞书机器人：在飞书群里「设置 → 群机器人 → 添加机器人 → 自定义机器人」，复制 webhook 地址，粘贴到「推送规则」页保存。
2. 添加规则：选指标 → 选条件 → 填阈值 → 填提醒内容 → 添加。
3. 程序每 3 分钟自动检查一次，命中且过了冷却期就推送到飞书；也可点「立即检查并推送」手动试一次。

可选指标：市场情绪分、炸板率、晋级率、涨停家数、最高连板、上证指数涨幅。

> 冷却时间用于防止同一条件短时间内反复推送。程序需一直运行才会自动提醒。

## 自选看板与配置

自选标的、飞书地址、规则都保存在 `config.json` 里，也可在网页上改。想自己加自选，直接用文本编辑器打开 `config.json`，在 `watchlist` 里复制一行改代码和名字即可（代码 6 位，ETF 如 `510300`）。

选股策略保存在 `indicators.json` 里，每条策略含通达信公式代码和选股配置。

```
├── indicators.json           # 选股策略（通达信公式 + 配置）

├── start.bat                 # Windows 启动脚本
├── core/                     # 后端核心
│   ├── data.py               # 行情/K线数据层（腾讯+新浪）
│   ├── market.py             # 市场概览（指数/涨停池/板块/量能）
│   ├── sentiment.py          # 情绪分算法
│   ├── emotion_history.py    # 历史情绪趋势
│   ├── legu.py               # 乐咕乐股历史数据
│   ├── backtest.py           # 内置指标回测引擎
│   ├── indicators.py         # 技术指标库（MA/MACD/KDJ/RSI/BOLL）
│   ├── tdx.py                # 通达信公式解释器
│   ├── screener.py           # 选股引擎（全市场+异步）
│   ├── rules.py              # 规则引擎（条件触发+冷却）
│   └── notifier.py           # 飞书推送
├── templates/
│   └── index.html            # 单页应用入口
├── static/
│   ├── app.js                # 前端逻辑
│   ├── style.css             # 样式
│   └── echarts.min.js        # 图表库
└── data/                     # 本地缓存（自动生成）
```
