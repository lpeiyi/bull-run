# 牛来

专为你定制的 A股 / 基金ETF 短线盯盘工具。基于免费公开数据源，把「技术指标回测」和「条件触发推送」做成了网页版，双击就能用，不需要会编程。

## 快速开始

1. 先装一次依赖（仅第一次）：
   ```
   pip install -r requirements.txt
   ```
2. 双击 `start.bat`，浏览器会自动打开 `http://127.0.0.1:8000`。
3. 用完直接关闭那个黑色窗口即可。

## 四个页面

| 页面 | 用途 |
|------|------|
| **指标回测** | 输入一个标的代码 + 选指标 + 调参数，回测它在历史上的收益表现 |
| **市场情绪** | 看当前短线情绪是冰点还是过热（0~100 分） |
| **推送规则** | 预设条件（如「情绪 < 30」），满足时自动推到飞书 |
| **自选看板** | 看自选标的和主要指数的实时行情 |

## 指标回测怎么用

1. 输入代码，例如 `510300`（沪深300ETF）、`159915`（创业板ETF）、`600519`（贵州茅台）。
2. 选一个指标，改参数（不改就用默认值）。
3. 点「开始回测」，会显示：总收益、年化收益、最大回撤、胜率、交易次数，以及资金曲线和每一笔买卖明细。

支持的指标和大致逻辑：

- **MACD 金叉死叉**：DIF 上穿 DEA 买入，下穿卖出，经典趋势指标。
- **KDJ 金叉死叉**：K 上穿 D 买入，下穿卖出，短线敏感。
- **RSI 超买超卖**：RSI 从超卖线上穿买入、从超买线下穿卖出，抓反转。
- **布林带 均值回归**：跌破下轨买入、突破上轨卖出，震荡市适用。
- **均线 趋势跟踪**：价格上穿均线买入、下穿卖出。

> 回测用的是前复权日K线，默认含双向万分之2.5的手续费。回测结果只代表「这套指标在过去的表现」，不代表未来。

## 市场情绪分怎么看

情绪分 = 涨停家数分 + 封板牢固分 + 晋级率分 + 连板高度分，合计 0~100：

| 分数 | 状态 | 含义 |
|------|------|------|
| 0~25 | 冰点 | 涨停稀少、赚钱效应差，常是中长线分批布局区间 |
| 26~45 | 偏冷 | 适合低吸、控制仓位 |
| 46~65 | 正常 | 不温不火，按节奏操作 |
| 66~80 | 偏热 | 注意追高风险、重视止盈 |
| 81~100 | 过热 | 涨停潮常伴随分歧，短线控制仓位防回撤 |

## 推送规则怎么设

1. 先配置飞书机器人：在飞书群里「设置 → 群机器人 → 添加机器人 → 自定义机器人」，复制 webhook 地址，粘贴到「推送规则」页保存。
2. 添加规则：选指标（如「市场情绪分」）→ 选条件（小于）→ 填阈值（30）→ 填提醒内容 → 添加。
3. 程序会每 3 分钟自动检查一次，命中且过了冷却期就推送到飞书；也可以点「立即检查并推送」手动试一次。

可选指标：市场情绪分、炸板率、晋级率、涨停家数、最高连板、上证指数涨幅。

> 冷却时间用于防止同一条件短时间内反复推送。程序停止运行时不会检查推送，需要让程序一直开着才会自动提醒。

## 自选看板与配置

自选标的、飞书地址、规则都保存在 `config.json` 里，也可以在网页上改。想自己加自选，直接用文本编辑器打开 `config.json`，在 `watchlist` 里复制一行改代码和名字即可（代码 6 位，ETF 如 `510300`）。

## 数据来源与时效

- 实时行情：腾讯行情（A股/ETF 约几秒级）
- 历史K线：腾讯前复权日K
- 涨停/炸板/晋级/连板：东方财富涨停四池（仅保留约 15 个交易日）
- 历史涨停/跌停/炸板家数：乐咕乐股（2020-02 至今，用于拉长情绪曲线）
- 全部免费，无需注册。数据仅供研究参考，可能因接口调整而失效。

## 风险提示

本工具仅供个人学习研究，所有回测结果与情绪指标均为历史统计，不构成任何投资建议。股市有风险，入市需谨慎。
