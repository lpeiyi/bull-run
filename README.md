# 牛来

专为你定制的 A股 / 基金ETF 短线盯盘工具。基于免费公开数据源，把市场概览（含情绪专区与自选）、智能选股、条件推送做成了网页版，双击就能用，不需要会编程。

## 快速开始

1. 先装一次依赖（仅第一次）：
   ```
   pip install -r requirements.txt
   ```
2. 双击 `start.bat`，浏览器会自动打开 `http://127.0.0.1:8000`。
3. 用完直接关闭那个黑色窗口即可。

## 三个 tab

| tab | 用途 |
|------|------|
| **市场概览** | 首页。大盘实时行情、涨跌统计、指数K线、指数走势对比、市场量能、行业领涨领跌、综合黄金行情、情绪专区（情绪分+等级+历史趋势+冰点次日表现）、自选标的实时行情 |
| **智能选股** | 用通达信公式选股。支持自定义公式编写、语法检查、全市场选股、单标的回测、定时选股推送飞书 |
| **推送规则** | 预设条件（如「情绪 < 30」），满足时自动推到飞书；也支持选股结果的定时推送 |

## 市场概览（首页）

首页聚合了盯盘所需的核心信息：

- **大盘实时行情**：上证、深证、创业板、科创50、上证50、中证500、沪深300、中证1000 实时行情
- **涨跌统计**：全市场涨跌幅分布
- **指数K线**：蜡烛图 + MA5/10/20 均线 + 成交量副图，可切换指数和周期（60/120/250日）
- **指数走势对比**：近 15/30/60 日归一化累计涨幅对比
- **市场量能**：两市实际总量能、预测总量能（对齐开盘啦 App 口径的分时橙色曲线，开盘尖峰 ~+18% → 快速下坠 → 0 附近 → 收敛）、241 分钟分时走势 + 近 20 日成交额历史（可切换「历史量能」tab）
- **行业领涨领跌 Top10**：行业涨幅榜与跌幅榜
- **综合黄金行情**：伦敦金 / COMEX 金 / AU9999，518880 × 每日系数折算近似估计
- **自选标的实时行情**：可添加 / 删除自选，实时报价
- **情绪专区**：四张卡片，详见下文

### 情绪专区

市场情绪相关功能整合为四张卡片：

- **卡片1 短线市场情绪**：情绪分（0~100）+ 等级 + 涨停/跌停/炸板率/晋级率/最高板 + 五维度贡献条形图（涨停家数 / 连板高度 / 晋级率 / 炸板率 / 跌停惩罚）
- **卡片2 情绪等级说明**：5 档等级卡片（冰点 / 偏冷 / 正常 / 偏热 / 过热），当前等级高亮
- **卡片3 情绪×指数走势大图**：时间窗口（近15日 / 3月 / 半年 / 1年 / 全部）+ 冰点阈值可调 + 重新计算按钮
- **卡片4 情绪低点·次日指数表现**：低点指数可切换（上证 / 中证500 / 科创50 / 创业板 / 沪深300）+ 统计（冰点样本数 / 平均次日涨幅 / 上涨概率）

#### 情绪分算法

情绪分（0~100）对齐开盘啦口径，五维度构成：

- **涨停家数主导**（对数映射）：18家≈0分，150家≈90分
- **连板高度溢价**：4板+1 … 8板+5
- **涨停晋级率修正**：昨日涨停今仍封板比例
- **炸板率修正**：封板率过低（炸板率 > 40%）才扣分
- **跌停惩罚**：跌停 ≤30 家视为正常，超出部分递减

| 分数 | 状态 | 含义 |
|------|------|------|
| 0~25 | 冰点 | 涨停稀少、赚钱效应差，常是中长线分批布局区间 |
| 26~45 | 偏冷 | 适合低吸、控制仓位 |
| 46~65 | 正常 | 不温不火，按节奏操作 |
| 66~80 | 偏热 | 注意追高风险、重视止盈 |
| 81~100 | 过热 | 涨停潮常伴随分歧，短线控制仓位防回撤 |

#### 历史情绪趋势（卡片3）

- 时间窗口：近15日 / 3月 / 半年 / 1年 / 全部（2020至今）
- 情绪分曲线 + 涨停家数柱状图 + 可叠加指数归一化曲线（上证、中证500、科创50、创业板指、沪深300）
- 历史主因子（涨停/跌停/炸板率）取自乐咕乐股，近15日叠加东财连板高度与晋级率

#### 情绪冰点 · 次日指数表现（卡片4）

统计情绪分 ≤ 阈值（默认30，可调）的冰点日，下一交易日各指数涨跌幅，含冰点样本数、平均次日涨幅、上涨概率。用于验证「冰点次日反弹」的历史规律。

## 智能选股

### 公式编辑

编写通达信公式进行选股，支持的技术指标函数：MA / EMA / SMA / REF / LLV / HHV / MAX / MIN / ABS / CROSS / RSI / MACD / KDJ / BOLL / IF / COUNT / EVERY / EXIST / BARSLAST，以及 CODELIKE / NAMELIKE / INBLOCK / CAPITAL 等股票属性函数。

支持语法：变量赋值（`:=` 中间变量 / `:` 输出变量）、逻辑运算（AND / OR / NOT）、比较运算、注释（`{ ... }`）、绘图属性自动忽略、指标属性访问（如 `KDJ.J`）。

### 选股配置

- **选股范围**：全市场 / 沪深A股 / 沪深300 / 中证500 / 自定义（沪市主板、深市主板、科创板、创业板、北交所）
- **排除条件**：ST/*ST、停牌/未交易、次新股
- **其他**：复权方式（前复权/后复权/不复权）、结果上限、排序方式
- **定时选股**：到点自动执行选股并推送飞书

### 选股回测

对单只标的用当前公式进行历史回测，显示累计收益、年化收益、最大回撤、胜率、盈亏比、交易次数，以及收益曲线和逐笔交易明细。

内置指标回测（5大经典策略）：

- **MACD 金叉死叉**：DIF 上穿 DEA 买入，下穿卖出
- **KDJ 金叉死叉**：K 上穿 D 买入，下穿卖出
- **RSI 超买超卖**：RSI 从超卖线上穿买入、超买线下穿卖出
- **布林带 均值回归**：跌破下轨买入、突破上轨卖出
- **均线 趋势跟踪**：价格上穿均线买入、下穿卖出

> 回测用前复权日K线，默认含双向万分之2.5手续费。回测结果只代表历史表现，不代表未来。

## 推送规则

1. 先配置飞书机器人：在飞书群里「设置 → 群机器人 → 添加机器人 → 自定义机器人」，复制 webhook 地址，粘贴到「推送规则」页保存。
2. 添加规则：选指标 → 选条件 → 填阈值 → 填提醒内容 → 添加。
3. 程序每 3 分钟自动检查一次，命中且过了冷却期就推送到飞书；也可点「立即检查并推送」手动试一次。

可选指标：市场情绪分、炸板率、晋级率、涨停家数、最高连板、上证指数涨幅。

> 冷却时间用于防止同一条件短时间内反复推送。程序需一直运行才会自动提醒。

## 开发与测试

回归测试覆盖情绪分算法、技术指标、通达信公式解释器、板块选源逻辑与选股清单容错，**全部离线可跑**（不会发起网络请求）。

```
# 首次准备：用 start.bat 指定的同一个 Python 装 pytest
"C:\Users\peiyilu\AppData\Local\Programs\Python\Python312\python.exe" -m pip install pytest

# 运行（在项目根目录）
"C:\Users\peiyilu\AppData\Local\Programs\Python\Python312\python.exe" -m pytest
```

改动 `core/` 里的算法后跑一遍，能立刻知道有没有弄坏既有逻辑。测试用例见 `tests/`，
需求 / 设计 / 任务见 `specs/add-regression-tests/`。

> 与 `scripts/` 下的脚本分工不同：**测试**管纯计算逻辑的回归；**脚本**管与外部打交道的核验与运维（接口契约、缓存体检）。

### K 线缓存体检与清理

`data/screener/klines` 会随选股/回测不断累积 K 线缓存。想知道它占多少、多少已过期、
有没有清单里已不存在的废弃文件，用 `scripts/cache_health.py`：

```
# 体检（只读，不改任何文件）
python scripts/cache_health.py report

# 清理预演（dry-run，只列出将删什么）
python scripts/cache_health.py clean

# 真正删除（需显式 --apply）
python scripts/cache_health.py clean --apply

# 连带删除复权孤儿（切换过复权方式后遗留的旧文件）
python scripts/cache_health.py clean --apply --orphan-adjust
```

安全约定：清理**默认只预演**，必须显式加 `--apply` 才动手；删除对象仅限「当前清单里已不存在的标的」；
删除粒度为整文件（删掉的文件下次访问会自动重拉，不影响回测取满 250 日）；
当股票清单本身处于**降级状态**（拉取失败回退旧缓存）时会**拒绝清理**，避免以残缺清单为基准误删。

### 股票清单的降级提示

启动后第一次选股会拉全市场清单（沪/深/北，约 5,500+ 只）并缓存 24 小时。
若拉取失败，程序会**自动回退到上一次的清单**而不是写入残缺结果，
`/api/screen/stock_list` 会返回 `degraded: true` 与 `reason` 说明。看到该标记时可访问
`/api/screen/stock_list?force=1` 重新拉取。

## 配置说明

- `config.example.json` 是示例配置模板，首次运行时复制为 `config.json`
- `config.json` 存储自选标的、飞书 webhook、推送规则，也可在网页上改。想自己加自选，直接用文本编辑器打开 `config.json`，在 `watchlist` 里复制一行改代码和名字即可（代码 6 位，ETF 如 `510300`）
- `indicators.json` 存储选股策略，每条策略含通达信公式代码和选股配置

## 风险提示

本工具仅供个人学习研究，所有回测结果与情绪指标均为历史统计，不构成任何投资建议。股市有风险，入市需谨慎。
