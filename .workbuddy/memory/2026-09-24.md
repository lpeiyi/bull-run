# 2026-09-24

## 项目梳理（bull-run / 牛来）

对项目做了一次整体梳理，记录关键事实便于后续对话复用。

### 项目形态
- A股/ETF 短线盯盘工具，Flask 单页应用，无数据库，JSON 文件持久化。
- 入口：`start.bat` → `app.py`（Flask + 3 个后台线程：情绪预热、监控轮询、选股）。
- 前端：`templates/index.html` + `static/app.js`(2689 行) + `style.css`(586) + ECharts。3 个 tab：市场概览 / 智能选股 / 推送规则。
- 数据源（全部免费、无鉴权）：腾讯 qt.gtimg.cn（实时行情）、新浪（历史日K）、东方财富（涨停四池/指数成交额）、乐咕乐股（历史情绪）。
- 推送：飞书 webhook（存于 config.json，已被 .gitignore 排除）。

### 代码规模（约 7,800 行）
- `app.py` 884（25 个路由 + 3 线程）
- `core/` 约 3,150：market 602、tdx 647、screener 574、gold 356、sentiment 261、data 171、backtest 142、emotion_history 131、legu 108、rules 84、indicators 58、notifier 19
- 前端约 3,700（app.js 2689 / style.css 586 / index.html 464）

### 架构依赖（关键）
- `core/data.py` 是唯一公共底座，被 market / screener / rules 依赖。
- `sentiment ← legu`；`emotion_history ← legu + sentiment`；`screener ← tdx + data`；`backtest ← indicators`；`rules ← sentiment + data`；`notifier`、`gold` 为叶子。
- 数据缓存：`data/screener/klines` 共 3660 个 CSV（约 72M），另有 emotion_trend_cache / legu_day_limit_cache / industry_map 等 JSON。

### 开发工作流

- git：main 分支，有 origin/main 远程。
