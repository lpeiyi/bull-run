### 环境踩坑（重要）
- pytest **无法在沙箱内安装**：沙箱代理 `http://127.0.0.1:5290` 连 PyPI 报 502 Bad Gateway

- 实际装到 **pytest 9.1.1**（远新于需求预估的 ≥7.0；`pythonpath` 配置项仍支持）

### 修掉的 2 个缺陷（测试暴露，当场修）
1. **`core/market.py` 缺模块级 `import math`** → `_clean_and_sort` 处理**浮点** `avg_pct` 时抛
   `NameError` → `get_boards()` 必炸 → `/api/overview` 冷启动首次请求 500，行业板块整块不可用。
   注意：**离线时两源皆空、循环不执行，反而掩盖该问题**，只有真实数据才触发。
2. **`core/tdx.py` 项提取不识别 `[...]` 下标后缀** → `KDJ.J > 80`、`MACD.DIF > 0`、`BOLL.UP > C`
   等「指标属性 + 比较运算」表达式全部畸形 → 选股公式**静默失效**（`get_signal` 吞异常返回 False）。
   修法：新增 `_find_matching_bracket` / `_consume_bracket_suffix`；`_extract_term_left` 增
   `]` 回溯分支；`_extract_term_right` 三处返回收尾统一消费下标后缀。

**Phase 1 关键发现（重要）**
- `core/market.py` 的 `_compare_and_pick` 与 `_clean_and_sort` 是定义在 `get_boards()`
  函数体内的**嵌套函数**，外部无法 import。ROADMAP 里"mock 掉网络测 `_compare_and_pick`"
  这条要先做结构性提取（提到模块级），已写成 requirements 的约束 C-3。
- 四类测试目标的可测性：`sentiment._calc_score` / `_is_dt_stock` 纯函数；
  `indicators` 全纯函数（仅依赖 pandas）；`tdx` 的 parse/evaluate/check_syntax 可用固定
  DataFrame 测；`market` 选源逻辑受上述嵌套问题影响。

**Phase 2 关键结论（写进 design.md）**

1. **环境是分裂的（最大坑）**：
   - 跑 app 的是系统 Python 3.12.10（`C:\Users\peiyilu\AppData\Local\Programs\Python\Python312\python.exe`，
     `start.bat` 指定），**有 pandas 3.0.3、无 pytest**。
   - 助手沙箱的托管 3.13.12 **既无 pandas 也无 pytest**。
   - 项目无 venv。→ 测试必须固定用系统 3.12.10 解释器，需补装 pytest。
     两种装法：A 装入系统 Python（推荐，零改动、与 app 同环境）／B 新建 `.venv`（需改 start.bat）。
2. **接口澄清**：`_is_dt_stock` 收的是**一个 dict**（`{"change_pct":..,"pure_code":..,"market":..}`），
   不是散开的参数；`_calc_score(zt_n, dt_n, max_height, promo_rate, break_rate)` 返回
   `(score, level, contributions)`；`evaluate_tdx` 返回 `(results_dict, signal)` 元组，
   "布尔序列"是 `results_dict[输出名]`。
3. **同类不同实现（别混）**：`indicators.kdj` 分母用 `.replace(0, 1e-9)`，
   `tdx.KDJ` 用 `.replace(0, np.nan)` + `fillna(50)`——高低价相等时结果不同，须分开测。
4. **需求措辞偏差 2 处**（已记进 design §9 待确认）：
   - AC-2.10「向上取整」实为 `int(round(...))` 四舍五入；
   - AC-5.2「返回布尔序列」实为元组中的输出序列。
5. **结构提取方案**：只把 `_compare_and_pick` / `_clean_and_sort` 原样搬到模块级，
   不提取 `_parse_sina` / `_parse_em`（它们依赖 requests 且测试不需要）。
   提取前需确认模块顶部有 `import math` / `import logging`。前后用 `scripts/verify_boards.py` 对照。
6. **测试套件设计**：`tests/` 下 4 个测试文件 + `conftest.py`（含 autouse 的 socket 阻断夹具，
   强制离线）+ 根目录 `pytest.ini`（`testpaths=tests`、`pythonpath=.`）。
   design.md 已按公式手算出 AC-2.9 各等级边界的参考输入表（待 Phase 4 首跑校验）。
